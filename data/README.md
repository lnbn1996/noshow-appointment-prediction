# Dữ liệu

Repo **không chứa** dữ liệu gốc.

- Tên: *Medical Appointment No Shows* (tệp `KaggleV2-May-2016.csv`, 110.527 dòng, 14 cột)
- Tác giả: Joni Hoppen, đăng trên Kaggle
- Tải về: https://www.kaggle.com/datasets/joniarroba/noshowappointments (cần tài khoản Kaggle)
- Giấy phép: **CC BY-NC-SA 4.0** (https://creativecommons.org/licenses/by-nc-sa/4.0/): phải ghi nguồn, chỉ dùng phi thương mại, nếu chia sẻ lại bản chỉnh sửa phải giữ cùng giấy phép.

Sau khi tải, nén thành `KaggleV2-May-2016.csv.zip` (hoặc dùng file zip Kaggle cung cấp, bên trong là `KaggleV2-May-2016.csv`) và đặt vào thư mục này. Tệp `.csv` và `.zip` đã được loại khỏi git qua `.gitignore`.

Lưu ý: giá trị `Yes` ở cột `No-show` nghĩa là bệnh nhân **vắng mặt**.
